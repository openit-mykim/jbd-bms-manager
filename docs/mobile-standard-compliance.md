# 모바일 앱 개발표준 준수 현황

기준: 위키 `infra/개발표준_도구/모바일앱_개발표준.md` (2026-11-10 제정본)
점검일: 2026-11-17 · 대상: `main` + PR `chore/typography-about`

이 앱의 성격: Android 전용, BLE 로컬 전용(서버·계정·클라우드 없음, D006), 웹뷰 없음, OpenJBD 고정 커밋 + overlay 빌드, GitHub Release로 APK 배포.
표준 2장의 적용 범위("2026-11-10 이후 신규 앱", "iOS 신규 개발 앱")에 정확히 들지 않지만, 해당되는 항목은 모두 맞춘다.
표준 0.4항에 따라 표준과 충돌하는 항목은 구현하지 않고 아래 "충돌·예외"에 근거와 대안을 기록한다.

## 2. 충돌·예외 (표준 0.4 보고)

| 항목 | 충돌 내용 | 현재 처리 | 대안 |
|---|---|---|---|
| 강제 업데이트·킬스위치(5.8) | 서버 호출이 필요해 로컬 전용(D006)과 충돌 | 미구현 | GitHub Releases API로 새 버전을 *안내*만 하는 선택 기능(차단 없음). 필요하면 사용자 결정 |
| 크래시 수집·단계 배포(7) | 클라우드 수집 도구(Crashlytics 등)는 D006과 충돌. 스토어 배포가 아니라 단계 배포 수단이 없다 | 미구현 | 크래시 로그를 로컬 파일로 남기고 사용자가 내보내기(공유)하는 방식 |
| 큰 숫자 글자 크기(5.7.2) | 가로 대시보드는 멀리서 읽는 용도로 32~80sp 숫자를 쓴다 | 예외로 유지(upstream `dashboard_*` 크기) | 표에 "Display-XL" 단계를 추가할지 표준 개정 제안 |
