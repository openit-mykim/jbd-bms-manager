## 3. 현재 구현 vs 격차

| 영역 | 현재(alpha.9) | 격차 |
|---|---|---|
| 밸런스 시작 전압 | `0x2A` 구현(2.0–4.5 V) | 없음 |
| 밸런스 정확도 | `0x2B` 구현(5–1000 mV) → **10 mV 직접 지원** | UI에서 의미·프리셋 노출 부족 |
| 밸런스 방법 | `0x2D` bit2(밸런스) / bit3(충전 밸런스) | "정적 균형" 개념 설명·선택 UI 부족 |
| 보호 지연 | **없음** | 신규 필요(영상 5번) |
| 시스템 셀 수 | **없음** | 신규 필요(영상 6번, 7~14S 전환) |
| SOC 포인트 | **없음**(문서상 후보 `0x12/0x13/0x32..0x35/0x42..0x47`) | 신규 후보 |
| 보호 카운터 | 커밋 전 스냅샷만(`0xAA` 읽기) | 진단 화면 미표시 |
| 프리셋/일괄 설정 | **없음** | 신규 필요(영상 1순위 불편) |
| 연결 상태 표시 | 개요에 연결 상태 존재 | 재연결·복구 동선 약함 |

## 4. UI 수정안

**U1. 연결 상태를 화면 최상단 1급 요소로**
- 전 탭 상단에 연결 배지: `연결됨(fresh) / 갱신 지연(N초) / 끊김 / 재연결 중`
- 값이 마지막 갱신 후 임계(예: 10초)를 넘으면 수치를 흐리게 + "갱신 지연" 라벨 → 낡은 값을 현재값으로 오독하는 사고 방지(영상 1번 대응)
- 끊김 시 원인 문구 + `재연결` 버튼, 재연결 실패 시 단계별 안내(앱 재설치 유도 금지)

**U2. 제어 탭 재배치 — "빠른 설정"을 최상단, 항목별 설정은 하위로**
- 기존 8개 섹션은 유지하되, 맨 위에 `빠른 설정(프리셋)` 진입점 추가
- 근거: 영상 3·6번 — 사용자가 실제로 원하는 것은 "한 번에 맞추기"

**U3. 값 표현 이중 표기 (구형 앱이 더 쉽다는 피드백 흡수)**
- 한 행에 `표시값(공학 단위)` + 보조줄 `raw(16진/10진)` + `판정 문구`(예: "권장 범위", "영상 권장값과 다름")
- 단위 환산 실수(0°C=2731, 팩 전압 10 mV/LSB, 전류 10 mA)를 화면에서 즉시 검산 가능하게

**U4. 밸런스 화면에 방법·정확도 상시 표시**
- 밸런스 탭 상단 요약에 `방법(정적 균형/충전 밸런스/사용 안 함)` + `정확도(10 mV)` + `시작 전압(3.7 V)` 노출
- "언제 밸런싱을 하는가"를 도식으로 1줄 설명(영상의 설명을 UI 문구로 흡수)

**U5. 위험 작업 확인 문구에 "왜"를 포함**
- 지연 관련: "지연이 짧으면 컷 복귀가 즉시 일어나 컨트롤러가 손상될 수 있습니다(2초→10초 권장)"
- MOS 차단: "차단 중에는 충·방전이 모두 끊깁니다" + 연결 전 차단 권장 안내(영상 33:05 스파크 팁)

**U6. 변경 전후 비교 + 되돌리기**
- 적용 전 `현재값 → 변경값` 목록(이미 구현)에 더해, **적용 직전 자동 백업**을 기본 제안(백업/복원과 연결)

## 5. 기능 보완안

**F1. 빠른 설정(프리셋) — 최우선**
- 입력: `셀 수(7~14S)` + `화학계(NMC/LFP)` + `사용 성향(보수/표준/최대 사용)`
- 출력: 셀·팩 전압, 과전류, 온도, 밸런스 시작/정확도, 지연까지 **일괄 스테이징** → 기존 트랜잭션(Read→Edit→Validate→Review→Apply→Read-back) 그대로 통과
- 안전: 프리셋은 "제안값 스테이징"만 수행하고 커밋 규칙은 그대로(전 항목 재검증 통과 시에만 커밋). 보수 프리셋은 영상 사용값(4.2 V / 2.8 V / 60 °C / 10초)을 기본으로, 최대 사용 프리셋은 경고 강화.

**F2. 밸런스 정확도 10 mV 노출 (이미 지원 — UI 보완)**
- `0x2B`가 5–1000 mV를 이미 지원하므로 기능 추가는 불필요. **한글 앱에서 구형 앱을 따로 써야 10 mV가 되던 제약을 우리 앱은 없앤다**는 점을 화면에 명시(프리셋 버튼: 10 mV / 15 mV / 20 mV).

**F3. 보호 지연 설정 (신규)**
- 후보: `0x3A..0x3F` 릴리스 지연 2×U8(초) — 온도/팩 전압/셀 전압/과전류
- 프리셋 기본 10초(영상 권장), 범위 검증 + 경고 문구 필수
- 물리 검증 전이므로 후보 등록 후 검증 절차 통과 시 노출

**F4. 시스템 셀 수 설정 (신규)**
- 후보: `0x2F`(U16, 1 cell)
- 셀 수 변경은 모든 전압 보호값의 기준을 바꾸므로 **프리셋과 묶어서만** 노출(단독 항목 편집은 고급 모드)

**F5. 보호 카운터 진단**
- `0xAA`(11×U16) 읽기 전용을 진단 패널에 표시: 충전 고온·단락·과전류 등 항목별 횟수
- 각 카운터 옆에 "확인할 것" 링크 문구(예: 고온 다수 → 냉각/설정 상향 검토)

**F6. SOC 포인트 조정**
- 후보: `0x12/0x13/0x32..0x35/0x42..0x47`(1 mV)
- 표시 SOC와 실제 체감이 어긋날 때 조정. 위험도 낮음, 후순위.

**F7. MOS 안전 워크플로**
- `연결 전 차단(스파크 방지)` 안내 + 원터치 시퀀스(차단 → 사용자 연결 → 해제)
- 차단 상태에서 전압·전류가 모두 0으로 보이는 정상 동작을 화면에 명시

**F8. 전류 캘리브레이션 10 mA 스케일 검증 (기존 항목, 대기)**
- 구현은 완료(무부하/충전/방전). raw 10 mA 가정이 실기기에서 맞는지 물리 검증 필요 — 릴리스 노트에 이미 명시.

## 6. 용어 확인 필요 (10 mA vs 10 mV)

요청에 "10 mA 전압오차 조절"로 적혀 있어 확인이 필요하다. 영상에서 나온 값은 **밸런스 정확도 10 mV(0.010 V)**이고, 우리 앱의 **10 mA**는 과전류·전류 캘리브레이션 raw 단위다. 서로 다른 항목이므로 어느 쪽을 말씀하신 것인지에 따라 착수 범위가 달라진다.
- (가) 밸런스 정확도 10 mV → F2(이미 지원, UI만 보완)
- (나) 전류 캘리브레이션 10 mA 스케일 → F8(물리 검증 대기)

## 8. 공통 전제 (기존 규율 유지)

- 신규 쓰기 항목은 전부 **후보 → 물리 검증 → 노출** 순서. 검증 전에는 프리셋에서도 제외하거나 "읽기 전용"으로 표시
- 프리셋도 커밋 규칙 동일: 전 항목 재검증 성공 시에만 `28 28` 커밋 + 커밋 후 재확인 읽기
- 위험 작업은 확인 문구 + old→new 비교 + 적용 전 백업 유지
- 알 수 없는 variant는 읽기 전용 유지
