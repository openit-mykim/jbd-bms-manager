## JBD BMS Manager v0.1.2

코드 리뷰(참고 구현 esphome-jbd-bms·jbdtool·JiabaidaBMS·SmartBMSUtility 대조), 쓰기 권한 게이트, 모바일 앱 개발표준 적용을 담은 릴리스입니다.

### 안전·쓰기 동작
- 쓰기 권한 게이트(D020): 검증되지 않은 BMS는 기본 읽기 전용입니다. 제어 화면에서 이 기기에 대해 "실험적 쓰기 허용"을 해야 쓸 수 있습니다. 허용은 주소·모델·펌웨어에 묶이며 철회할 수 있고, 모든 쓰기는 기기 내 감사 로그에 남습니다.
- MOS 제어(0xE1): 실시간 FET 상태로 명령 값을 만들고 EEPROM 커밋 없이 적용합니다(오류 카운터 초기화 없음). 다른 쪽 FET가 보호 동작으로 꺼져 있으면 거부합니다.
- 캘리브레이션: 보정 레지스터를 명령으로 다룹니다. 레지스터가 0으로 읽혀도 무부하 제로 보정이 누락되지 않습니다.
- 커밋 결과: BMS가 커밋을 거부하면 '커밋되지 않음', 응답이 없으면 '커밋 미확인'으로 표시합니다(이전에는 둘 다 '커밋 완료').
- 쓰기 직전 세션 안에서 관계 값을 다시 읽어 검증하고, 온도 보호값의 트리거·해제·순서 관계 검증을 추가했습니다.
- 화면 회전·언어 변경으로 BLE 연결과 쓰기 세션이 끊기지 않습니다. 재연결할 때마다 미커밋 팩토리 세션을 먼저 폐기합니다.

### 화면·품질
- 글자 크기·간격을 표준 크기표와 4dp 그리드로 맞췄습니다. 날짜·시간은 기기 로케일과 시간대로 표시합니다.
- 상세 화면에 '이력 삭제'를 추가했습니다. 이력 DB 형식이 바뀌거나 읽을 수 없으면 크래시 대신 이력을 새로 만듭니다.
- 중국어(간체) 제품 화면 번역을 추가했습니다(기계 보조 번역).
- 정지된 폴링 동안 오래된 값이 이력에 기록되지 않습니다.

### 현재 제한
- 실제 BMS 연결 상태의 실기기 검증은 아직 진행 전입니다(이슈 #23). `NOT HARDWARE VERIFIED`.
- debug key로 서명된 빌드이며, CI 실행마다 서명 키가 달라 **이전 버전 위에 업데이트 설치가 되지 않습니다.** 기존 앱을 삭제한 뒤 설치하세요(앱 내 이력·실험적 쓰기 허용·감사 로그가 함께 삭제됩니다). 고정 서명 키는 이슈 #9.
- 안전 밴드와 SOC 밴드는 앱 참고 표시이며 BMS 보호 동작을 보장하지 않습니다.
- JBD / Jiabaida의 공식 앱이 아닙니다.
