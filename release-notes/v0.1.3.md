## JBD BMS Manager v0.1.3

고정 릴리스 키 서명, 여러 BMS 관리, BLE 응답 견고화, 타이포그래피 표준을 담은 릴리스입니다.

### 설치 — 꼭 읽어 주세요
- 이번 버전부터 APK는 **고정 릴리스 키**로 서명됩니다(인증서 SHA-256 `BF:94:8E:45:…:6F:57:3F:AE`). 다음 버전부터는 삭제 없이 업데이트로 설치됩니다.
- v0.1.2 이하는 실행마다 다른 debug 키로 서명되어 있어, 이번 한 번은 **기존 앱을 삭제한 뒤 설치**해야 합니다. 앱 안의 이력·실험적 쓰기 허용·감사 로그가 함께 지워집니다.
- 확인: `apksigner verify --print-certs <apk>`의 인증서 SHA-256이 위 값과 같아야 합니다.

### 여러 BMS (#24)
- BMS를 여러 대 등록하고 별칭(최대 32자)을 붙이거나 이름을 바꾸고 삭제할 수 있습니다. 선택한 기기를 기억하고, 시작할 때는 선택한 기기에만 자동 연결합니다.
- BMS 목록의 '신호 확인'은 4초 동안 검색해 도달 여부와 RSSI를 보여 줍니다. 초록은 연결됨 또는 범위 안, 회색은 보이지 않음, 빨강은 연결 실패입니다.
- 이력, 저장 백업, 정비 기록을 기기별로 따로 저장합니다.
- 쓰기와 복원 전에 연결된 BMS가 선택한 기기인지 확인합니다. 다르면 프레임을 보내지 않습니다(D022). 백업은 내보낸 BMS에만 복원됩니다.

### BLE 견고화 (#30, D021)
- 타임아웃 뒤 늦게 도착한 응답은 300ms 동안 격리합니다. 쓰기 응답은 빈 payload일 때만 성공으로 봅니다. 그 밖의 응답은 커밋하지 않고 실패로 처리합니다.
- 연결 세대 번호로 이전 연결의 프레임을 버립니다. 프레임 조립이 어긋나면 1바이트씩 다시 동기화합니다. 전송 전에 취소된 설정 명령은 보내지 않습니다.
- MOS 화면은 0xE1을 읽지 않고 실시간 FET 상태만으로 표시·편집합니다.

### 화면·품질 (#9, #31)
- 글자 크기 단계마다 줄높이·자간을 정했고 자동 검사로 지킵니다.
- 앱 정보에 OpenJBD 원본 프로젝트 링크(MIT, © 2026 KFACBT)를 다시 넣었습니다. 앱 정보 머리 그림이 upstream 기본 Android 아이콘이던 것을 제품 아이콘으로 바꿨습니다.
- Android lint, Robolectric 화면 테스트, 실제 SQLite 이력 마이그레이션 테스트를 CI에서 실행합니다(단위 테스트 413건).
- 화면이 다시 시작될 때마다 상태 수집기가 중복으로 쌓이던 문제를 고쳤습니다(개요·설정·가로 대시보드).
- 릴리스 빌드 콜드 스타트: 약 0.2초(Note20 Ultra, 이전 debug 빌드 약 0.7초).

### 현재 제한
- 실제 BMS를 연결한 실기기 검증은 아직 하지 않았습니다(#23). `NOT HARDWARE VERIFIED`. 쓰기 응답 형식(빈 payload)은 공개 문서 기준 가정입니다. 실제 형식이 다르면 쓰기가 커밋 없이 실패합니다.
- 중국어(간체) 번역은 기계 보조 번역이며 원어민 검토 전입니다(#31).
- 안전 밴드와 SOC 밴드는 앱 참고 표시이며 BMS 보호 동작을 보장하지 않습니다.
- JBD / Jiabaida의 공식 앱이 아닙니다.
